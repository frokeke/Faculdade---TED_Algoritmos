# Faculdade---TED_Algoritmos
TED realizado para a disciplina de Algoritmos 2

Este código tem o intuito de similar, de forma extremamente simples, um sistema de combate de RPG.
Para compilar o código, será necessário um compilador capaz de compilar linguagem C++.

## Como compilar este código:

### Passo 1:

No terminal, vá até o arquivo onde queira armazenar o projeto e execute o seguinte comando:

```
git clone <URL_PROJETO>
```

### Passo 2:

Neste mesmo terminal, insira o seguinte comando

```
g++ -TED_2.cpp -o TED_2
```
_Exemplo dado utilizando compilador GCC_

Feito isso, divirta-se.
